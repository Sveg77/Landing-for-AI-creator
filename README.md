# Landing for AI Creator

Лендинг для Светланы Глазовой (услуги по разработке цифровых продуктов).

## Состав проекта

- `index.html` — структура страницы и интерактивная логика
- `styles.css` — стили, адаптив, анимации и цветовая система
- `photo_2026-04-06_17-31-02.jpg` — фото на главном экране
- `Моя монограмма зеленый.png` — логотип в шапке
- `TZ.md` — исходное ТЗ

## Как открыть сайт

1. Откройте папку проекта.
2. Запустите файл `index.html` в браузере.

## Что уже реализовано

- адаптивный лендинг с 17 блоками
- единый визуальный стиль и типографика
- фиксированная шапка с логотипом и меню
- анимированный главный заголовок
- кастомный курсор для интерактивных элементов (десктоп)
- интерактивный стек карточек в блоке отзывов
- форма заявки с чекбоксом согласия

## Быстрая доработка

- контент редактируется в `index.html`
- визуальные изменения вносятся в `styles.css`
- изображения можно заменить файлами с теми же именами или обновить пути в `index.html`
